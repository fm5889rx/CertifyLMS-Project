# 受け⼊れ条件

## S-B-01 質問掲⽰板

【受講⽣】質問スレッドの投稿
1. /qa-board/create から資格選択 + タイトル + 本⽂を⼊⼒してスレッドを投稿できる
2. 成功時に作成されたスレッド詳細(/qa-board/{thread})へリダイレクトする
3. フラッシュメッセージ「質問を投稿しました。」が表⽰される
【受講⽣】質問スレッドの編集
1. 投稿者本⼈がタイトル・本⽂を編集できる(資格は変更不可)
2. 投稿者以外はアクセスできない
3. 成功時にスレッド詳細へリダイレクトし、フラッシュメッセージ「質問を更新しました。」が

表⽰される

【受講⽣】質問スレッドの削除
1. 投稿者本⼈は回答 0 件のスレッドのみ削除でき、成功時にフラッシュメッセージ「質問を削除

しました。」が表⽰される

2. 回答有りのスレッドは削除できず、フラッシュエラー「回答が付いているスレッドは削除でき

ません。」が表⽰される

【受講⽣】質問スレッドの解決マーク / 解除
1. 投稿者本⼈のスレッド詳細にのみ解決マーク / 解除ボタンが表⽰される(本⼈以外には表⽰され

ない)

2. マークすると解決済みバッジと解決⽇時が表⽰される(フラッシュ「質問を解決済にマークしま

した。」)

3. 解除すると未解決表⽰に戻り解決⽇時の表⽰も消える(フラッシュ「質問を未解決に戻しまし

た。」)

【受講⽣・コーチ】回答の投稿・編集・削除
1. 受講⽣ / コーチが回答を投稿・編集・⾃削除できる
2. 編集はインライン編集ではなく回答編集フォームに遷移して⾏う
3. 各操作の成功時にフラッシュ表⽰(「回答を投稿しました。」「回答を更新しました。」「回答

を削除しました。」)

【受講⽣・コーチ】スレッド⼀覧の絞り込み・ページネーション
1. 受講⽣は公開済資格すべて、コーチは担当資格のみのスレッドを⼀覧で⾒られる
2. 資格別 / 解決状態 / キーワード(タイトル / 本⽂ / 回答本⽂の OR 部分⼀致)で絞り込みできる
3. 新着順 20 件 / ページのページネーションが実装されている
【受講⽣・コーチ】スレッド詳細の回答表⽰
1. スレッド詳細画⾯で配下回答が古い順(投稿順)で全件表⽰される(回答ページネーションなし)
【管理者】モデレーション
1. /admin/qa-board 経由で全資格(公開停⽌資格含む)のスレッドを横断閲覧できる
2. 任意のスレッド / 回答を無条件で削除できる(スレッド削除時に配下回答も連動削除、フラッシ

ュ「質問を削除しました。」)

3. 管理者の画⾯にはスレッド投稿 / 編集 / 解決マークの操作ボタンは表⽰されない(モデレーショ

ンは削除のみ)

【コーチ・受講⽣】担当外・公開停⽌資格へのアクセス制御
1. コーチは担当外資格のスレッドを直接 URL 指定 or ⼀覧クエリで指定しても閲覧できない(資格

存在は隠蔽しない)

S-B-02 ⾯談パックのマスタ管理

【管理者】⾯談パック⼀覧の絞り込み
1. ⾯談パック管理画⾯で⼀覧を閲覧できる
2. パック名キーワード(部分⼀致)+ ステータス(下書き / 公開中 / アーカイブ)フィルタで絞り込め

る

3. 公開中を優先する並び順で表⽰される
【管理者】⾯談パックの新規作成
1. 新規作成すると下書き状態で作成される
2. 作成された⾯談パックの詳細画⾯へリダイレクトし、フラッシュメッセージ「⾯談パックを作

成しました。」が表⽰される

【管理者】⾯談パックの編集
1. 編集画⾯から基本情報(パック名 / 説明 / ⾯談回数 / 価格 / Stripe 価格 ID / 並び順)を更新できる
2. このフォームではステータス(下書き / 公開中 / アーカイブ)は変更されない
3. 成功時に詳細画⾯へリダイレクトし、フラッシュメッセージ「⾯談パックを更新しました。」

が表⽰される

【管理者】⾯談パックの削除
1. 下書き / アーカイブ状態の⾯談パックを削除すると⼀覧画⾯へリダイレクトし、フラッシュメ

ッセージ「⾯談パックを削除しました。」が表⽰される
2. 公開中は詳細画⾯に削除ボタンが表⽰されず削除できない
【管理者】⾯談パックのステータス遷移
1. 公開(下書き → 公開中)/ アーカイブ(公開中 → アーカイブ)/ 下書きへ戻す(アーカイブ → 下書き)

の 3 操作がそれぞれ遷移元の状態でのみ実⾏できる

2. 成功時に詳細画⾯へリダイレクトし、フラッシュ表⽰(下書き→公開「⾯談パックを公開しまし
た。」/ 公開中→アーカイブ「⾯談パックをアーカイブしました。」/ アーカイブ→下書き「⾯
談パックを下書きへ戻しました。」)

【管理者】新規作成 / 編集フォームのバリデーション
1. 違反時に⽇本語エラーが表⽰される(パック名 = 必須・100 ⽂字以内 / 説明 = 任意・2000 ⽂字

以内 / ⾯談回数 = 必須・1〜100 の整数 / 価格 = 必須・0〜1,000,000 円の整数 / Stripe 価格 ID =
任意・255 ⽂字以内 / 並び順 = 任意・0 以上の整数)

【受講⽣・コーチ】⾯談パック管理へのアクセス制御
1. 受講⽣ / コーチは⾯談パック管理の画⾯(⼀覧 / 詳細 / 新規作成 / 編集)にアクセスできない
本チケットの機能に対するテスト (Unit / Feature 等) が実装されている
